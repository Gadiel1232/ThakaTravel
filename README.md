# ThakaTravel

ThakaTravel es un proyecto web orientado a la gestión de experiencias y paquetes turísticos.

## Descripción

El sistema permite a los usuarios consultar destinos, paquetes turísticos,
rutas, información turística y gestionar diferentes aspectos relacionados
con sus viajes.

## Objetivo

Desarrollar una plataforma que facilite la planificación y gestión de viajes
mediante herramientas digitales.

## Tecnologías

- HTML
- CSS
- JavaScript
- PHP
- Laravel
- MySQL
- Git
- GitHub
