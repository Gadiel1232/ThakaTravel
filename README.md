# ThakaTravel

## Sistema web para la gestión de experiencias y paquetes turísticos

ThakaTravel es un proyecto web orientado al sector turístico, cuyo propósito
es facilitar la planificación, organización y gestión de viajes mediante una
plataforma digital.

El sistema busca integrar en un solo lugar información sobre destinos,
paquetes turísticos, rutas, alojamientos, reservas e información relevante
para el viajero.

---

## Descripción del proyecto

ThakaTravel está pensado como una plataforma que permite a los turistas
consultar diferentes alternativas de viaje y organizar sus experiencias de
manera sencilla.

El proyecto contempla funcionalidades relacionadas con la búsqueda de
destinos, creación y consulta de paquetes turísticos, rutas personalizadas,
geolocalización, audioguías, información turística, alojamientos y gestión
del viaje.

También se plantea el uso de herramientas de inteligencia artificial para
generar y modificar itinerarios de acuerdo con las preferencias del usuario.

---

## Objetivo general

Desarrollar una plataforma web que facilite la planificación y gestión de
experiencias turísticas, integrando información de destinos, rutas, paquetes,
reservas y herramientas digitales de apoyo al viajero.

---

## Objetivos específicos

- Permitir el registro y acceso de los usuarios.
- Gestionar la información del perfil y las preferencias del turista.
- Mostrar destinos y paquetes turísticos.
- Permitir la consulta de información detallada de los destinos.
- Crear y consultar rutas turísticas.
- Incorporar funcionalidades de geolocalización.
- Proporcionar audioguías relacionadas con los lugares visitados.
- Facilitar la consulta de alojamientos y reservas.
- Generar itinerarios personalizados.
- Integrar herramientas de inteligencia artificial.
- Presentar información turística, noticias y alertas relevantes.
- Facilitar la administración de destinos, paquetes y reservas.

---

## Funcionalidades principales

### Usuarios

- Registro de usuario.
- Inicio de sesión.
- Gestión del perfil.
- Administración de preferencias.

### Destinos y paquetes

- Catálogo de destinos turísticos.
- Información detallada de cada destino.
- Galería e información visual.
- Consulta de paquetes turísticos.
- Paquetes prearmados.
- Reserva de paquetes.

### Rutas y mapas

- Creación de rutas personalizadas.
- Cálculo de rutas optimizadas.
- Consulta del tiempo y costo del recorrido.
- Visualización de rutas mediante mapas.

### Geolocalización y audioguías

- Obtención de la ubicación del usuario.
- Consulta de destinos cercanos.
- Audioguías asociadas a ubicaciones turísticas.

### Inteligencia artificial

- Registro de preferencias del viaje.
- Generación de itinerarios.
- Modificación de itinerarios mediante inteligencia artificial.

### Información turística

- Noticias y alertas.
- Información sobre bloqueos y restricciones.
- Calendario cultural.
- Índice turístico.

### Hospedajes y reservas

- Consulta de alojamientos.
- Información de hospedajes.
- Reserva de experiencias.
- Consulta de reservas realizadas.

### Administración

- Gestión de destinos.
- Gestión de paquetes.
- Gestión de reservas.
- Gestión de información turística.
- Consulta de estadísticas.

## Metodología de desarrollo

El proyecto se organiza utilizando la metodología ágil Scrum.

El trabajo se divide en diferentes épicas, historias de usuario y sprints,
permitiendo organizar las funcionalidades y realizar un seguimiento
progresivo del desarrollo.

---

## Control de versiones

Git se utiliza como sistema de control de versiones para registrar los
cambios realizados durante el desarrollo del proyecto.

el seguimiento del código y sus diferentes versiones.
